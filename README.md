# CampusAutoLoginWeb · 校园网断了，它自己把认证做完

对着电脑点登录点到手酸的人，看这个。

每个学校都有这么一套东西：连着校园网 Wi-Fi，但上不了外网，得打开浏览器、被 302 甩到认证页、填学号密码、选出口、点登录。早上开会前、凌晨掉线、笔记本合盖再打开，重复一百遍。

这个项目把它变成一个**没有窗口、没有托盘图标、开机自己蹲着**的后台进程：探到上不了网、又在校园网里，就自己开 Edge 把那张表填完并提交，再用探针确认真的通了才记成功。

```
探外网(204) ──通──> 睡 3600 秒
     │
    不通
     ▼
在校园网吗？（默认网关 / WAN 网关 / 门户 TCP）
     │是
     ▼
Edge 走 AC 302 → 拿带密文参数的 /eportal/login.jsp → 填表提交 → 204 确认
```

## 为什么不是「定时脚本点几下」

因为这套认证**不能自己编 POST**。页面 token 来自重定向链的末端，表单里每个隐藏字段（`wlanuserip`、`wlanacname`、`nasip`、`mac`…）都是 AC 现场给的；自己拼一份发过去，服务端会回你一句「您采用了收藏的历史页面」或者「Web认证接入设备不存在」。

所以这里的做法是**让浏览器自己走一遍**：脚本用自写的 CDP 客户端驱动你已装的 Edge，先访问 `1.1.1.1` 之类的外部地址触发 AC 的 302，落到真正的登录页，再照着页面上的 action 和隐藏字段提交。填表、点击、跳转全是真浏览器行为，AC 认的就是这个。

## 三分钟用起来

```powershell
# 1. 丢到一个不会再动的位置，比如 D:\CampusAutoLoginWeb
# 2. 复制示例配置，填自己的学号密码
copy autologin-web.example.json autologin-web.json

# 3. 装（写开机自启 + 后台拉起 + 校验进程）
双击 install-autologin-web.cmd

# 4. 想确认它判断得对不对（不影响后台那份）
双击 run-autologin-web.cmd --diagnose
```

`--diagnose` 会直接告诉你：账号是谁、默认网关多少、现在通不通外网、在不在校园网、是不是免打扰时段、这一轮该不该动。

## 它脑子里在算什么

| 判据 | 怎么判 | 为什么这样判 |
| --- | --- | --- |
| 有没有外网 | 请求 `generate_204` 看是不是 204 | 不看 `ping`，很多校园网 ICMP 通但 HTTP 被劫持 |
| 在不在校园网 | 默认网关 = `192.168.1.1`，或 WAN 网关 `10.100.0.1` 可达，或门户 TCP 可达 | 三个条件任一成立就算，避免换宿舍/换楼层后判错 |
| 该不该登录 | 不在外网 + 在校园网 + 不在免打扰时段 | 少了第三条会白跑，服务端直接拒 |
| 登成功了没 | 提交后再打一次 204 探针 | 页面说「登录成功」不算数，能上网才算 |
| 失败了怎么办 | 1.6 倍退避，最长 5 分钟一次 | 网络恢复瞬间容易撞上限流，退避比死磕有效 |

## 免打扰时段：这不是 bug，是账号策略

`00:00 - 06:30` 这段时间，认证服务器会直接回「不在认证时段内」。脚本默认整段睡过去，一次都不试——反复试只会刷一屏失败日志。

想让它在这个时段也硬试，把 `window_login` 改成 `true`；想换时段就改 `skip_start` / `skip_end`。

## 配置项

| 键 | 说明 | 默认 |
| --- | --- | --- |
| `user` / `password` | 学号 / 密码 | 无，自己填 |
| `portal` | 认证门户 | `http://172.172.255.20/` |
| `ac` | 重定向器 | `10.100.0.235` |
| `net` | 出口：`校园网` / `中国移动` / `中国联通` | `校园网` |
| `skip_start` / `skip_end` | 免打扰窗口 | `00:00` / `06:30` |
| `interval` | 断网时多久探一次 | 15 秒 |
| `online_interval` | 已在线时多久看一眼 | 3600 秒 |
| `login_wait` | 点完登录等多久确认 | 25 秒 |
| `debug_port` | Edge 调试端口 | 9333 |
| `headless` | 无头模式（调试建议 `false`） | `false` |

## 日志

`autologin-web.log` 是一行一条 JSON，看 `event` 和 `ok`：

| event | 含义 |
| --- | --- |
| `start` | 守护启动，`note` 里带着间隔、窗口、窗口内是否登录 |
| `skip` | 撞到免打扰窗口，睡到 `skip_end` |
| `login` | `ok=true` 表示探针确认能上网；`ok=false` 时 `note` 写明每个候选页为什么失败 |
| `abort` | 已有实例在跑，本次退出 |
| `once` | `--once` 单次运行结果 |

## 常见坑

**浏览器开了但没填进去**：多半落在的不是带参数的登录页。看日志 `note` 里哪一条写着「无登录表单」，以及最后有没有走兜底 HTTP。

**提示「Web认证接入设备不存在」**：提交时缺 AC 带来的密文参数。必须让 AC 的 302 把浏览器带到登录页，别自己拼 POST。

**双击后窗口一闪就没了**：正常。首次启动打印几行信息、把后台拉起来、约 6 秒自动关窗。去任务管理器看 `python.exe`，或看日志有没有新行。

**日志中文乱码**：日志是 UTF-8。PowerShell 5 的 `Get-Content` 默认按本地代码页读会乱，用记事本 / VS Code / `Get-Content -Encoding UTF8` 就正常。

## 卸载

双击 `uninstall-autologin-web.cmd`：删开机自启 → 删计划任务 → 杀监督窗口 → 杀 python → 关 9333 上的调试浏览器 → 删锁。跑完就彻底不启动了。

只想临时停：任务管理器结束 `python.exe`（自启项还在，下次开机会再起）。

## 依赖与边界

- Windows + Edge（Chrome 同源的话改一下可执行名也行），**不装任何第三方库**：`cdp.py` 用的是标准库 socket + WebSocket 帧，`urllib` 探针。
- 只登**你自己**的账号。没有字典、没有枚举、没有验证码识别——这页本来就没有验证码字段。
- 学校换门户、换 AC、换字段名，脚本要跟着改；这类工具天生是「一个学校一份」的。
